win2nix →

A single-file Python command-line tool that turns text files from Windows into Linux form: UTF-8, LF line endings, no BOM. Detects CP1251, CP866, KOI8-R and UTF-16 on its own and makes a backup when in doubt (RU). Утилита командной строки в одном файле на Python: приводит текстовые файлы из Windows к виду Linux — UTF-8, переводы строк LF, без BOM. Сама определяет кодировку (CP1251, CP866, KOI8-R, UTF-16), при сомнении делает резервную копию.

vabuter.github.io/win2nix
